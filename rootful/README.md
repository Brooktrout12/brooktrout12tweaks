# Rootful tweaks

Packages in this folder are for rootful jailbreaks. Check each package's iOS requirements before installing.

## Meteora (Touch Fix)

- **Version:** 1.0-13+touchfix1
- **Compatibility:** iOS 10.x, armv7 and arm64, rootful
- **Package ID:** com.ikilledappl3.meteora
- **Dependencies:** Cydia Substrate and Cephei
- **Original authors:** iKilledAppl3 and Skittyblock

[Download Meteora (Touch Fix)](./Meteora_1.0-13%2Btouchfix1_iphoneos-arm.deb)

Fixes gesture and view accumulation in Meteora's iOS 9-style lock screen. Install the DEB over Meteora using Filza or a package manager, then respring.

The original saved build is provided unchanged. Its source archive, build notes, and MIT license are included in the package under `/usr/share/doc/meteora-touchfix/`. The bundled notes identify this as a device-test build; device verification is not claimed here.
